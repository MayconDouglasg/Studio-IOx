# storyboard — step 0: a client with no approved ID yet

Read this only when no episode of the client has `motion/id_aprovada/` (the client's first storyboard).

1. Make **6–9 test stills** in code (`tools/codigo.py novo`, one still per second, `render.mjs --at`) with the
   episode's **real text** (the speaker's words, the real partner and tool names), not lorem ipsum. Each still tests one
   thing: background, type pair, icon style, a diagram, a card over the face, a camera travel frame.
2. Publish them on a review page (same rules as step 7 of SKILL.md: `db`, one collection per round, every still marked
   one by one + a general note). Ask the open style questions (STYLE.md 1b) in the same pass.
3. Log every mark in STYLE.md section 7 and change the rules in STYLE.md 1/1b/2/6 and client.json. Repeat until every
   still is approved or dropped (expect 2–4 rounds).
4. Join the approved stills (from any round) into one ID sheet: `<episode>/motion/id_aprovada/` with the frames
   (`01..09`) + one contact sheet. STYLE.md points to that folder; the storyboard starts only then.
