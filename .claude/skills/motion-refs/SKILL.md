# motion-refs

Goal: maximum style accuracy for minimum tokens. Raw reference videos are watched ONCE by a local
script; Claude reads only the compact digests, and only the new ones. All later work reads
`clients/<slug>/STYLE.md`.

## Layout
The client folder can live anywhere (`python tools/studio.py where <slug>` prints it; a new client is
created with the `novo-cliente` skill).
```
<client folder>/
  client.json         machine-readable tokens (colors, fonts, camera roles, motion) the tools read
  STYLE.md            style bible (copied from clients/_template/STYLE.md for a new client)
  brand/              logo (svg/png), fonts, palette, any brand guide
  refs/canal/         the client's own published videos  -> what the channel already IS
  refs/inspiracao/    outside animations the user likes   -> ideas to ADAPT, never copy
  refs/**/<video>.txt optional note next to a video, e.g. "transição em 0:42, fundo não"
  _digest/            generated by tools/ingest.py (never edit by hand)
```

## Getting the videos (links → refs/)
Ask for **3–6 of the client's own channel videos** (recent, in the format being made now; fewer than 3 is
not enough to average pacing and palette) and download them from the links:
```
python tools/studio.py refs <slug> <url> <url> ...              -> refs/canal
python tools/studio.py refs <slug> <url> --inspiracao           -> refs/inspiracao
python tools/studio.py refs <slug> <channel /videos url> --playlist --max 5   (newest 5)
```
yt-dlp, best H.264 mp4 up to 1080p (`--altura 720` for long videos), the title as the file name, files
already there skipped, playlists only with `--playlist`. Then go on to A.
- **Only the client's own channel, or references the client sent** (links in the briefing or the chat).
  These files are for study only (digest → STYLE.md); they never go inside a video.
- **Never download third-party footage for use inside a video**: b-roll and supporting footage come only from
  the `imagens-apoio` skill's licensed sources (client folder, Magnific, Pexels, Pixabay, AI).
- A link that needs a login, a private video or a members-only video: ask the user for the file instead.

## A. New references were added  →  ingest
1. `python tools/ingest.py <slug>` (add `--max-seconds 240` for long videos when only the
   style matters; 4 min of a 20-min episode is plenty). It prints the digests still pending.
2. For each pending digest ONLY: read `digest.json`, then look at `sheet.jpg` once
   (one image ≈ one shot per tile, in time order; `sheet_times_s` gives each tile's time).
   Never open the video files themselves, and never re-open sheets already folded in.
3. Fold findings into STYLE.md:
   - `refs/canal/*` → sections 0–2, 4. Average the numbers across channel digests.
   - `refs/inspiracao/*` → section 3, phrased as "technique → how it fits this identity".
   - User notes (`notes`) outrank anything inferred from the sheet.
   - Measured colors / fonts also go into `client.json` (the tools read tokens from there, not from prose).
     Thin colours (grid lines, dividers, outlines, shadows) are measured on the sheet and written as a mix of
     existing tokens (tint / shade / opacity of one of them), never as a new colour. A font file gets its glyph
     count checked before it enters `fonts.*.file` (novo-cliente, Lessons).
   - Edit existing rules instead of appending duplicates; keep evidence tags; keep it short.
4. Set `"in_style": true` for those entries in `_digest/index.json`.
5. Tell the user in 3–6 lines what changed in the style bible, and ask about anything ambiguous
   (e.g. "the accent orange appears in 2 of 5 videos — brand color or one-off?").

## B. Starting a motion for a client
1. Read the client's `STYLE.md` and list `brand/`. Do not read `_digest/` or refs.
2. Only if the brief explicitly names a reference ("like the intro of ep 12"), open that one
   `sheet.jpg`.
3. No approved ID yet (no `motion/id_aprovada/` named in STYLE.md): start with the test stills of
   `storyboard` step 0 before any storyboard — that is the only place the ID test is described.
4. Put the project in the client's projects folder (`python tools/studio.py new-episode <slug> <name>`),
   following the root CLAUDE.md render contract. Brand accuracy in the scorecard = STYLE.md section 6.

## C. Feedback on a delivered motion
Whenever the user approves, rejects or corrects something, add a dated line to STYLE.md section 7
and change the rule it touches. This log is what makes the next motion land faster.
